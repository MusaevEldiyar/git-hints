# хеш коммита : 
1) Автор 
2) Дата
3) Содержимое файлов в репозитории на момент коммита
4) Ссылка на предыдущий, или родительский (англ. parent), коммит. </br>
5) <HEAD> Он указывает на коммит, который сделан последним (то есть на самый новый).
git log

#  Вывести только первые несколько символов хеша каждого коммита и комментарии к ним.
git log --oneline

# Статусы untracked/tracked, staged и modified
1) untracked (англ. «неотслеживаемый») - Новые файлы в Git-репозитории / нет предыдущих версий
2) staged (англ. «подготовленный») - после git add / до commit
3) tracked (англ. «отслеживаемый») - зафиксированы с помощью git commit /  и которые были добавлены в staging area командой git add
4) modified (англ. «изменённый») - Git сравнил содержимое файла с последней сохранённой версией и нашёл отличия. Например, файл был закоммичен и после этого изменён.
git status
